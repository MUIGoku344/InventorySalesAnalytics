# Inventory & Sales Analytics System

A Java-based inventory management and sales analytics application designed to simulate how a business can track products, inventory levels, and sales performance.

## Features

- Add and search for products
- Update inventory quantities
- Record sales transactions
- Automatically update stock after sales
- Calculate total sales revenue
- Track total units sold
- Identify the best-selling product
- Detect low-stock products
- Save and load inventory data using CSV files
- Prevent duplicate product IDs
- Basic input validation

## Technologies

- Java
- Object-Oriented Programming
- Java Collections
- File I/O
- CSV data storage
- Git & GitHub
- IntelliJ IDEA

## Project Structure

- `Product` - Represents individual products
- `Sale` - Represents sales transactions
- `Inventory` - Manages products, stock, and sales
- `SalesAnalyzer` - Performs sales analytics
- `FileManager` - Handles CSV persistence
- `Main` - Provides the interactive console interface
